# Gestión Estudiantil

Programa básico para administrar la información de estudiantes: listado, búsqueda y registro de nuevos estudiantes.

## Estado del proyecto
- Etapa 1: repositorio y primera interfaz (Front-End) en `frontend/`.
- Los datos son de ejemplo y se guardan solo en memoria (no hay base de datos ni backend todavía).

## Cómo ver la interfaz
Abre `frontend/index.html` en el navegador.

```
GestionEstudiantil/
```
